Curio for Mac

Curio is the premier brainstorming and project-management app for visual thinkers. Its innovative freeform interface lets you gather, associate, and recall ideas effortlessly, while managing notes and documents within dynamic idea spaces—your digital whiteboard, notebook, and sketchpad in one.

Unlimited Idea Spaces

Create boundless idea spaces in every project. Freely place text, images, URLs, documents, emails, movies, and sounds anywhere on the canvas. Customize with note paper, graph paper, or linen textures to match your creative flow.

Robust Status Shelf

Refactored for reliability, the Status Shelf handles background task retrieval across opened and unopened projects without race conditions, deadlocks, or sync issues—keeping your workflow seamless.

Intelligent Backups

Automatic backups now create zipped project archives asynchronously. Save space, speed up cloud syncs, evade Spotlight clutter, and open projects faster without interruptions.

Enhanced Project Management

Smarter link resolution via updated Project Mappings ensures curio:// links work instantly on open and save. New windows preserve session state, and locked collections allow flexible item management.

Superior Markdown Support

Code blocks gain padding, borders, and spacing options. Use tildes or backticks, specify pixel or percentage font sizes—perfectly tuned like GitHub or ChatGPT for precise, professional rendering.

How It Works

Step 1: Start a New Project

Create a project and add unlimited idea spaces. Drag in ideas, notes, files, or media freely—build collages that spark inspiration.

Step 2: Organize and Customize

Arrange elements with auto-spacing, lock positions for stability, and style spaces to your taste. The Status Shelf tracks tasks reliably in the background.

Step 3: Refine with Markdown

Enhance notes with advanced code blocks using tildes, backticks, or custom fonts. Links resolve instantly for fluid navigation.

Step 4: Backup and Access

Enable zipped backups for efficiency. Open in new windows with preserved state—your ideas stay secure and ready.
